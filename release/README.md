# RedFoxExpand 0.1.0 发布包

## 文件

- `RedFoxExpand-1.8.9-0.1.0.jar`：Minecraft 1.8.9 Forge 客户端 Mod；
- `CHANGELOG.md`：本版本功能和修复说明；
- `README.md`：安装与校验说明。

## 安装

1. 安装 Minecraft 1.8.9 和 Forge `11.15.1.2318`；
2. 将 `RedFoxExpand-1.8.9-0.1.0.jar` 放入实例的 `mods/` 目录；
3. 启动客户端并启用符合 `assets/Kyeitk/` 规范的材质包。

本 Mod 仅需客户端安装。
